# リバーシ

AIと対戦できるリバーシ（オセロ）のWebアプリです。
AIの強さは「入門」から「十段」までの11段階。最善手を教えてくれるアシストや、盤面の解説もついているので、遊びながら上達できます。

**▶ アプリを開く: https://trendgoing-stack.github.io/reversi/**

登録やログインは不要です。無料で使えます。

## できること

- **段位を選んで対局** — トップ画面で、AIの段位を入門・初段〜十段から選べます。各段位には「枚数を優先する」「4手先を読む」など、どんな打ち方をするかの説明が付いています。先手（黒）・後手（白）も選べます
- **置けるマスのハイライト** — 石を置けるマスに印が付きます。「ヒント」ボタンで表示・非表示を切り替えられます
- **一手戻る・一手進む** — 打ち直したいときは「戻る」で自分の手番まで戻れます。棋譜をタップすると、その局面へ移動できます
- **アシスト** — ONにすると、自分の手番のたびに最善手を金色で光らせます。もう一度押すとOFF。対局を始めるときは必ずOFFから始まります
- **解説** — ONにしている間、局面が変わるたびに解説を出し直します。いまの形勢、打てる場所の数、隅の状況、次の一手の候補とその理由、注意すべき手がわかります
- **盤面の座標** — 「盤面」ボタンで a1〜h8 の座標を表示します。解説の手の位置を確かめるときに便利です
- **勝敗記録** — 段位ごとの勝ち・負け・勝率と、最近の対局結果をトップ画面で確認できます

## iPhoneで使う

ホーム画面に追加すると、アプリのように全画面で使えます。一度開けば、電波のない場所でも起動します。

1. **Safari** で上のリンクを開く
2. 画面下の共有ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」をタップ

> [!IMPORTANT]
> Safariで開いた場合とホーム画面から開いた場合では、勝敗記録が**別々に保存**されます。
> 記録を残したい対局は、ホーム画面のアイコンから開いて遊ぶようにしてください。

AndroidやPCでも、ChromeやEdgeなどのブラウザで同じように使えます。

## アプリの更新

新しいバージョンが用意できると、アプリを開いたときに画面の上部に
**「更新があります（タップで再読み込み）」** と表示されます。
タップすると最新版に切り替わります。表示されないときは、すでに最新版です。

いま使っているバージョンは、トップ画面をいちばん下までスクロールすると確認できます。

## データについて

- 勝敗記録や設定は**お使いの端末の中だけ**に保存されます。サーバーには送信されないので、ほかの人に見られることはありません
- そのため、**機種変更やブラウザのデータ削除をすると記録は消えます**
- 記録はトップ画面の「記録をすべて消す」でリセットできます
- 勝敗は1対局につき1件だけ記録されます。終局後に「戻る」で指し直しても、二重には記録されません
- アクセス数の計測に [GoatCounter](https://www.goatcounter.com/) を使っています。記録されるのは「どのページが何回開かれたか」だけで、クッキーは使わず、勝敗記録などアプリの中身が送られることはありません

## はじめて遊ぶときは

まずは **入門** か **初段** から始めるのがおすすめです。
迷ったときは「アシスト」をONにして最善手を見ながら打ち、気になる場面で「解説」を押すと、なぜその手が良いのかがわかります。
勝てるようになってきたら、段位を一つずつ上げていきましょう。
