# リバーシ

AI と対戦できるリバーシ（オセロ）。ビルド不要の HTML / CSS / JavaScript だけで動く PWA です。
データはすべてブラウザの localStorage に保存され、サーバーには何も送りません。

## 公開先

https://trendgoing-stack.github.io/reversi/

`main` に push すると GitHub Actions（`.github/workflows/deploy.yml`）が
そのまま GitHub Pages へ公開します。ビルド工程はありません。

```bash
git add -A && git commit -m "変更内容" && git push
```

### iPhone で遊ぶ

1. Safari で上記 URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. 追加したアイコンから起動すると、全画面表示＋オフラインでも遊べます

## できること

| 機能 | 説明 |
| --- | --- |
| トップ画面 | 段位を説明つきのカードで選択。自分の石の色、段位ごとの勝敗記録もここで確認できます |
| AI 対戦 | 段位は **入門・初段〜十段** の11段階。上の段ほど深く読み、手のブレも小さくなります |
| 置けるマスのハイライト | 「ヒント」ボタンで表示・非表示を切り替え |
| 一手戻る / 一手進む | 自分の手番まで一気に戻ります。棋譜のタップでも任意の局面へ移動できます |
| アシスト | **モード式**。一度ONにすると、自分の手番のたびに最善手を金色で光らせ続けます |
| 解説 | 形勢・着手の自由度・隅の状況・次の一手の候補と理由・注意点を文章で表示 |
| 盤面 | a1〜h8 の座標を盤の外周と空きマスに表示 |
| 勝敗記録 | 段位ごとの勝敗・勝率と直近の対局結果を保存（端末内のみ） |

### 画面の流れ

```
トップ画面（段位・石の色・勝敗記録）
   ├─「対局開始」→ 対局画面
   └─「対局中の盤面にもどる」→ 中断した対局の続きへ

対局画面
   ├─「← トップ」→ 盤面を保ったままトップ画面へ
   └─ 終局 → 結果ダイアログ（もう一局 / 見直す / トップ画面へ）
```

段位は今後さらに追加予定です。`js/engine.js` の `LEVELS` に1行足すだけで増やせます
（`tagline` と `note` がそのままトップ画面の説明文になります）。

## 遊び方のメモ

- 自分の石の色（先手＝黒／後手＝白）と段位はトップ画面で選びます。「対局開始」で新しい対局が始まります。
- アシストは一度押すとONのまま続きます（設定は次回起動時も保持されます）。
- 勝敗記録は「1対局につき1件」です。終局後に戻って指し直しても二重には記録されません。
- PC ではキーボードの ← → でも戻る・進むが操作できます。

## 開発

サーバーは不要ですが、Service Worker を試すときはローカルサーバー経由で開いてください。

```bash
python -m http.server 8123
# http://localhost:8123 を開く
```

アイコン（PNG）を作り直す場合：

```bash
node scripts/generate-icons.mjs
```

### ファイル構成

```
index.html            画面の骨組み
css/style.css         見た目（ダークテーマ・iPhone のセーフエリア対応）
js/engine.js          盤面ロジックと AI（アルファベータ探索・置換表・終盤読み切り）
js/worker.js          AI の思考を裏で走らせる Web Worker
js/app.js             画面まわり（描画・操作・解説の文章生成・勝敗記録）
sw.js                 オフライン用 Service Worker
manifest.webmanifest  ホーム画面に追加するための設定
```

### AI の仕組み

`js/engine.js` はネガマックス法（アルファベータ枝刈り）で読みます。

- 反復深化＋置換表（Zobrist ハッシュ）＋手の並べ替えで、同じ時間でより深く読む
- 評価は「マスの価値・確定石・着手可能数・フロンティア石・石数」を進行度で重み付け
- 終盤は残りマスが少なくなると最後まで読み切る（段位が上がるほど早い段階から）
- 段位ごとに読みの深さ・持ち時間・評価に乗せる揺らぎ・ランダム率を変えている

思考は Web Worker で動くので、AI が考えている間も画面は固まりません。
